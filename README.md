# DSH 记账挂件 · 优香角色包

> Sensei，今天的支出我也有好好记下来哦。

这是 [DeepSeek-Balance-Whale-Widget](https://github.com/MeteorNOX/DeepSeek-Balance-Whale-Widget) 的一个 **早濑优香（Blue Archive / 碧蓝档案）角色包**。

安装后，会将 DSH 右下角的余额挂件替换成优香主题：让千年科学学园「研讨会」的会计优香来替 Sensei 看着 DeepSeek API 的余额、支出和预算。🥰

## 效果

* 👩‍💼 将右下角角色替换为 **手里拿着可乐饼的睡衣优香**
* 🔊 点击音效替换为优香的 **「せん～せ～い～」**
* 💬 加入一组符合优香性格的随机台词
* 😭 加入优香表情包 / 账单优香等气泡图片
* 💰 将余额、单轮消耗、今日支出等文字改为更符合“优香帮 Sensei 管账”的表达
* ⚠️ 修改余额不足与今日预算提醒
* 💳 余额不足时可直接通过「经费补充」前往 DeepSeek 充值页面

例如：

> 这轮也记下了 ¥0.03今天已经花了 ¥2.14

以及：

> Sensei，您的 DS 余额只剩 ¥10 啦~**>> 经 费 补 充 <<**

> Sensei，今天的支出已经达到 ¥10 啦，请控制一下预算哦~

## 安装

### 前置条件

请先安装并正常运行：

[DeepSeek-Balance-Whale-Widget](https://github.com/MeteorNOX/DeepSeek-Balance-Whale-Widget)

本项目只是角色包，不包含挂件本体。

### Windows

下载或克隆本仓库后，在仓库目录运行：

    .\install.ps1

安装脚本会自动将优香角色、音效、图片与相关配置加入 DSH 挂件。

安装完成后刷新 DSH Web 页面即可。

> 建议安装前关闭正在编辑挂件配置的页面，避免配置同时被修改。

## 卸载

在仓库目录运行：

    .\uninstall.ps1

脚本会移除本角色包添加的相关内容。

## 关于台词

本角色包把原本单纯的 API 用量信息稍微做了角色化处理。

核心思路是：

* API 余额 → **经费**
* 每轮调用费用 → **记下一笔**
* 今日消耗 → **今天已经花了**
* 消费阈值 → **预算**
* 充值 → **经费补充**

因此优香不只是站在右下角，而是真的在帮 Sensei 管账。

……至少她是这么认为的。
